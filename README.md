# case_customer_churn
## Проектный практикум
### Кейс 2: Прогнозирование оттока абонентов телеком-оператора (Churn Prediction)

📋 Описание кейса

требуется определить вероятность прекращения обслуживания абонента (оттока) на основе подключенных
телеком-услуг, истории оплат, типа контракта и сформировать перечень
ключевых факторов риска ухода.
